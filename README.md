# Avionics Firmware

Firmware for the avionics of our rocket competing at **EuRoC** (European Rocketry Challenge).

This repository will hold most of the project code, including the flight computer and DAQ (data acquisition) firmware for STM32 microcontrollers, shared drivers, tests and supporting Python tools.
