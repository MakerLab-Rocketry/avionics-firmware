# Repository Structure

> **Note:** This describes the planned layout of the repository. Some folders may not exist yet and will be added as development progresses.

```
avionics-firmware/
|
|-- flight-computer/          STM32CubeMX project 1
|   |-- Core/                 generated by CubeMX
|   |-- Drivers/              ST HAL and CMSIS
|   |-- cmake/                generated build configuration
|   |-- App/                  flight computer application
|   |-- flight-computer.ioc
|   `-- CMakeLists.txt
|
|-- daq/                      STM32CubeMX project 2
|   |-- Core/
|   |-- Drivers/
|   |-- cmake/
|   |-- App/                  DAQ application
|   |-- daq.ioc
|   `-- CMakeLists.txt
|
|-- shared/                   reusable code for both projects
|   |-- inc/                  public headers (.h)
|   `-- src/                  implementations (.c)
|
|-- tests/                    driver and application tests
|-- tools/                    Python utilities and data decoders
|-- docs/                     interface and test documentation
|-- README.md
`-- .gitignore
```

## Folder overview

| Path | Description |
|------|-------------|
| `flight-computer/` | STM32CubeMX project for the flight computer (FC). |
| `daq/` | STM32CubeMX project for the data acquisition (DAQ) board. |
| `*/Core/`, `*/Drivers/`, `*/cmake/` | Generated by STM32CubeMX (HAL, CMSIS, startup code, build config). Avoid hand-editing outside `USER CODE` blocks. |
| `*/App/` | Application code specific to that board. |
| `*/<name>.ioc` | STM32CubeMX configuration file (pins, clocks, peripherals). |
| `*/CMakeLists.txt` | Build definition for that board. |
| `shared/` | Code reused by both projects (e.g. sensor drivers, protocols, utilities). |
| `shared/inc/` | Public headers (`.h`). |
| `shared/src/` | Implementations (`.c`). |
| `tests/` | Driver and application tests. |
| `tools/` | Python utilities, e.g. telemetry/log data decoders. |
| `docs/` | Interface and test documentation. |
